КАМЕРТОНА — музыкальный блог
================================

ЗАПУСК
Откройте файл index.html двойным щелчком или через Visual Studio Code.
Сервер, npm и установка зависимостей не требуются.

СТРУКТУРА
index.html       — главная страница
catalog.html     — каталог с фильтрами
search.html      — живой поиск по публикациям
favorites.html   — сохранённые материалы
article.html     — универсальная страница статьи
about.html       — о блоге и авторе
contacts.html    — контакты и демонстрационная форма
css/style.css    — адаптивный дизайн и тёмная тема
js/data.js       — база из 16 полноценных публикаций
js/script.js     — поиск, фильтры, избранное и интерфейс
images/          — локальные SVG-иллюстрации
robots.txt       — правила индексации
sitemap.xml      — карта сайта

Все функции работают при обычном открытии через file://.
Избранное и выбранная тема сохраняются в localStorage браузера.

Примечание для публикации: перед размещением на реальном домене замените
https://kamertona.example в sitemap.xml и robots.txt на адрес сайта.
